# StowPaste v0.1.3

本次更新补齐了历史记录的键盘操作和图片预览，并修正工具栏按钮的纵向对齐。

- 选中记录后按 Backspace 删除，删除后自动选中相邻记录；长按不会连续删除。
- 选中图片后按空格，或点击缩略图、预览按钮查看原图，再按空格或 Esc 返回列表。剪贴板图片和本地图片文件均可预览，原图缺失时会显示明确状态。
- 编辑标题时，Backspace 和空格保持正常的文字输入行为。
- 移除“再次按快捷键粘贴”的提示条，保留原有快速粘贴操作；预览沿用现有磨砂面板、圆角及系统／自定义主题。
- 修复左侧工具栏图标偏上的问题，使其与右侧操作按钮纵向居中对齐。

兼容 macOS 14 及以上，提供 Apple silicon／Intel 通用构建和中英文 DMG。删除操作针对历史记录及其未使用的图片副本，系统剪贴板和原始文件不受影响。

## Changes

- Backspace deletes the selected history record and selects its neighbor. Holding the key does not remove additional records.
- Space opens original-image previews; Space or Escape returns to history. Thumbnails, row actions, and the context menu offer the same preview. Missing original files have an explicit state.
- Space and Backspace retain their normal behavior during title editing.
- Removed the quick-paste hint while preserving the quick-paste shortcut. Previews follow the panel's native materials and system or custom theme.
- Centered the toolbar tabs vertically alongside the action buttons.
- Restored the published guide, privacy page, and download metadata through the maintained static website export; fixed overlapping header controls on narrow screens.

## Install and update

Quit the running copy before dragging StowPaste into Applications. If the existing Accessibility permission is stale after replacing the app, remove its old entry, add `/Applications/StowPaste.app` again, and reopen it.

The build uses identity-free ad-hoc signing. The app and DMGs are not Developer ID signed or Apple-notarized. Review the source and SHA-256 before choosing **Open Anyway** in System Settings → Privacy & Security. See the [guide](https://stowpaste.aiware.store/docs/) and [privacy page](https://stowpaste.aiware.store/privacy/).
