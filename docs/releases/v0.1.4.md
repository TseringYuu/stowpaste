# StowPaste v0.1.4

本次热修复处理选中／粘贴普通文本时的重复历史更新，并防止应用发出的粘贴快捷键再次触发面板。

- 保存历史时，只发布发生变化的收藏和记录，不再逐条发布整份历史。2,000 条记录的回归场景中，一次选中或粘贴的列表更新从 2,001 次降为 1 次。
- 每次绘制列表只计算一次选中记录，避免每一行重复筛选和排序整个历史。
- 为应用发出的 Command-V 标记来源；即使键盘事件延迟送达、临时屏蔽已结束，也会直接放行，避免重新唤出面板或触发快速粘贴。
- 旧收藏置顶数据会一次性迁移并立即保存，保留原有顺序和其他置顶状态。

## Changes

- Publish only actual history/favorite changes during persistence, removing thousands of redundant list updates during selection and paste.
- Resolve selection once per rendered list instead of sorting history for each row.
- Identify injected Command-V events independently of the temporary suppression timeout, preventing delayed shortcut reentry.
- Persist legacy favorite migration immediately and retain favorite order and other pins.

## Install and update

Quit the running copy, open the DMG, and drag StowPaste into Applications. Keep existing local history. If Accessibility permission becomes stale after replacement, remove the old entry, add `/Applications/StowPaste.app` again, and reopen it.

Supports macOS 14 or later on Apple silicon and Intel. The application uses an identity-free ad-hoc signature; the app and disk images are not Developer ID signed or Apple-notarized. See the [guide](https://stowpaste.aiware.store/docs/) and [privacy page](https://stowpaste.aiware.store/privacy/).

## Verification and limits

The Swift Testing suite covers text-paste publication counts, clipboard contents and persistence, legacy migration, delayed synthetic-event identity, and the existing keyboard/deletion/image-preview behavior. The mounted offscreen-panel regression selects and pastes 30 times with 2,000 generated text records and a private test pasteboard. `Scripts/verify_paste_memory.sh` terminates the test process tree above 512 MiB RSS or after 60 seconds, without posting shortcuts to another app or reading/writing the user's general clipboard.

All 16 tests passed, including the watched stress scenario, which reported a peak RSS of 94 MiB. Both localized Universal DMGs passed payload-version, signature, architecture, and SHA-256 checks. Website checks covered the current download metadata, homepage, guide, privacy page, and mobile guide layout.

The system-wide OOM report was not reproduced in the isolated test. This release removes confirmed update amplification and a delayed event-reentry risk; it does not establish that every possible OOM trigger has been identified.
